Hi, I'm Alyssa, a Computer Science graduate from **UC Santa Cruz** who likes working close to the machine: operating systems, concurrency, networking, and the C code that ties them together.

---

### What I work on

- **Systems & concurrency.** Multithreaded HTTP servers and proxies built on thread pools, reader-writer locks, and thread-safe queues. Synchronization problems like dining philosophers. Kernel work in the Pintos teaching OS.
- **Networking.** TCP client/server and peer-to-peer chat applications using raw sockets.
- **Data structures & algorithms.** Graph algorithms (BFS, DFS, strongly connected components), sparse matrices, red-black-tree dictionaries, and an arbitrary-precision integer library in C++.
- **Compression & low-level I/O.** A Huffman encoder/decoder with bit-level readers and writers, and a hex dump tool.
- **Programming languages.** Lambda calculus, interpreters, and type inference in Haskell.
